    FIRST CONNECTION
    Prepare once. Then use the wizard.
    An IP address identifies the router. Credentials, a reachable management service, and a trusted certificate authorize the connection.
    1. Use a separate management connection. Connect your computer to the existing management LAN, then open WinBox. Save a backup in Files and a configuration export. Copy both to your computer.
    2. Prepare a certificate. Configure a trusted TLS server certificate whose subject alternative name includes the router IP, or export your existing server certificate over a trusted connection and obtain its SHA-256 fingerprint. See README.md for the OpenSSL command.
    3. Enable HTTPS. In IP → Services, enable www-ssl, choose that certificate, and restrict Available From to your management computer or VPN subnet. Your firewall must permit that access.
    4. Prepare a user. In System → Users, create a dedicated account. Its group needs read,write,rest-api. Do not give the app your main administrator password. Router permissions are broad; use a trusted local computer.
    5. Connect here. Enter the router IP, HTTPS port, account and password. For a self-signed certificate, enter the independently verified SHA-256 fingerprint.
    6. Choose your scenario. Inspect the detected interfaces, build a plan, read the operations, and apply after confirming your backup.
    What this pilot includes
    One router connection at a time, local-user hotspot profiles, two spare-port network setups, random PIN vouchers, printing, CSV export, account disabling with cookie/session cleanup, and an additive change journal.
    Scope and compatibility
    Built against the RouterOS v7 REST interface. RouterOS 7.24.2 compatibility is unverified until hardware acceptance testing. No automatic RouterOS upgrade, router reset, multi-WAN, PPPoE provisioning, Wi-Fi driver configuration, payment collection, User Manager migration, calendar-expiry engine, or remote multi-user hosting is included.
    Windows, macOS and Linux can run the Python application. Phones and tablets are not standalone hosts in this release. The server binds to this computer only.
